# 🤍 Pour Toi — Notre Sanctuaire d'Amour

Une application web romantique, moderne et élégante conçue sur mesure pour réconforter, rassurer et redonner confiance à ta moitié après de petits moments de doute ou de tensions.

---

## 📁 1. Structure des Dossiers & Fichiers

Pour que le site fonctionne parfaitement et que toutes vos photos s'affichent instantanément, assure-toi d'avoir cette organisation :

```text

├── index.html               # Page web principale (lettre d'amour, galerie, boîte à réconfort)
├── style.css                # Design moderne, pastel, animations douces & responsive mobile
├── app.js                   # Interactions (générateur de mots doux, lightbox, musique douce, câlin virtuel)
├── README.md                # Ce guide d'utilisation et de déploiement
└── images/                  # Dossier contenant vos photos personnelles
    ├── 8065.jpg             # Affiche WANTED One Piece Photomaton
    ├── 7807.jpg             # Elle au cinéma, concentrée avec sa petite moue adorable
    ├── 7723.jpg             # Selfie spontané sous les plafonniers (main cachant le visage)
    ├── 7595.jpg             # Selfie voiture "Avec mon trophées dhomme du match"
    ├── 7542.jpg             # Selfie nocturne souriant en voiture (main sur l'épaule/cou)
    ├── 7543.jpg             # Silhouette de sa main levée avec bagues dans la voiture (ou 7543.svg déjà inclus)
    └── illustration_douce.jpg # (ou 15456488623456909014.jpg) Illustration cocon d'amour (ou illustration_douce.svg déjà inclus)
```

> **Note sur les images bonus :**  
> Les 5 photos principales que tu as fournies sont déjà copiées et renommées dans le dossier `images/`.  
> Pour `7543.jpg` et `illustration_douce.jpg` (ou `15456488623456909014.jpg`), de magnifiques illustrations artistiques au format SVG sont déjà intégrées et prennent le relais automatiquement. Si tu disposes de tes fichiers JPG d'origine, il te suffit de les glisser dans le dossier `images/` avec ces noms exacts et ils remplaceront instantanément les illustrations !

## 🚀 2. Mettre en Ligne sur GitHub Pages en 3 Clics (Gratuit & Rapide)

GitHub Pages te permet d'obtenir un lien internet sécurisé (`https://ton-pseudo.github.io/pour-toi/`) que tu pourras lui envoyer directement par message.

### Étape 1 : Créer le dépôt sur GitHub
1. Connecte-toi sur [GitHub.com](https://github.com).
2. Clique sur le bouton vert **"New"** (ou **"+"** en haut à droite > **"New repository"**).
3. Nomme ton dépôt (par exemple : `pour-toi` ou `notre-cocon`).
4. Laisse le dépôt en **Public** et clique sur **"Create repository"**.

### Étape 2 : Déposer tes fichiers
1. Sur la page du dépôt fraîchement créé, clique sur **"uploading an existing file"** (ou glisse-dépose directement).
2. Dépose l'ensemble des fichiers :
   - `index.html`
   - `style.css`
   - `app.js`
   - Le dossier `images/` complet (avec toutes les photos dedans).
3. En bas de la page, clique sur le bouton vert **"Commit changes"**.

### Étape 3 : Activer GitHub Pages
1. Dans ton dépôt GitHub, clique sur l'onglet **Settings** (en haut à droite).
2. Dans le menu de gauche, clique sur **Pages** (dans la section *Code and automation*).
3. Sous la section **Build and deployment** :
   - Source : Sélectionne **Deploy from a branch**.
   - Branch : Choisis **main** (ou **master**), dossier `/ (root)`, puis clique sur **Save**.
4. Patiente 1 à 2 minutes : GitHub génère ton lien magique du type :  
   👉 `https://ton-pseudo.github.io/pour-toi/`

## ✨ 3. Ce que ta Copine va Découvrir sur son Téléphone

- 💌 **Une lettre d'amour réconfortante** : Des mots sincères qui dédramatisent les disputes récentes et lui rappellent sa beauté, sa force et sa place essentielle dans ta vie.
- 📸 **Une galerie interactive sur-mesure** :
  - L'avis de recherche One Piece en mode pirate légendaire.
  - La photo cinéma avec un mot tendre sur sa petite moue boudeuse.
  - Le selfie spontaneous plafonnier rappelant que sa lumière transperce tout.
  - Le souvenir de voiture rappelant qu'elle est ton véritable trophée.
  - Le selfie nocturne chaleureux rappelant qu'elle est ton havre de paix.
  - Chaque photo s'agrandit en plein écran d'un simple toucher (lightbox douce).
- 🔐 **L'Escape Game Interactif de Notre Amour (7 Étapes)** :
  Un jeu d'énigmes avec barre d'avancement et cadenas animé pour déverrouiller votre coffre-fort d'amour :
  1. *Étape 1* : `aliya` (Le prénom de celle qui illumine ta vie)
  2. *Étape 2* : `23/12/2004` (Ta date de naissance)
  3. *Étape 3* : `10/12/06` (Sa date de naissance)
  4. *Étape 4* : `ryane` (Ton prénom, son protecteur et complice)
  5. *Étape 5* : `mon coeur` ou `mon bebe` (Vos surnoms d'amour au quotidien)
  6. *Étape 6* : `02/08/25` (Votre date gravée pour toujours)
  7. *Étape 7* : `je t'aime` (Le code ultime)  
  *Coffre-Fort Final :* Révélation du Grand Serment d'Amour d'Aliya & Ryane avec pluie de cœurs et d'or !
- 🌸 **La Boîte à Réconfort ("Ouvre ça quand...")** : Des onglets interactifs selon son humeur (doutes sur elle-même, peur des disputes, sentiment de ne pas être assez bien, fatigue...).
- 💖 **Le Bouton Cœur Magique** : Plus de 25 compliments personnalisés à débloquer avec une pluie de cœurs à chaque toucher.
- 💎 **Les 10 Vérités Gravées dans le Marbre** : 10 cartes à retourner au toucher pour lui rappeler tes promesses.
- 🎤 **Ton Chanteur Favori** : Ton morceau personnalisé directement intégré (via `music.mp3`), activable d'un simple toucher avec ondes sonores animées !
- 🫂 **Le Câlin Virtuel Final** : Un bouton interactif avec vibration tactile et un lien WhatsApp pré-rempli pour vous retrouver.
